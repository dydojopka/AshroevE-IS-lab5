### 3. Расчет отношения согласованности

Рассчитываем $\lambda$, умножая сумму каждого столбца суждений на соответствующую компоненту нормализованного вектора приоритетов:
$$\lambda = C_1W_1 + C_2W_2 + C_3W_3 + C_4W_4 + C_5W_5 + C_6W_6$$

Подставляем значения из таблицы:
$$\lambda = (2.051 \cdot 0.451) + (5.200 \cdot 0.231) + (18.5 \cdot 0.053) + (11.833 \cdot 0.089) + (24.0 \cdot 0.036) + (8.083 \cdot 0.140)$$
$$\lambda = 0.925 + 1.201 + 0.981 + 1.053 + 0.864 + 1.132 = 6.156$$

Вычисляем индекс согласованности (ИС) по формуле:
$$ИС = \frac{\lambda - n}{n - 1}$$
Где $n = 6$ (число сравниваемых требований).
$$ИС = \frac{6.156 - 6}{6 - 1} = \frac{0.156}{5} = 0.0312$$

Находим отношение согласованности (ОС). Для случайной матрицы 6-го порядка табличное значение случайной согласованности равно 1.24[cite: 31].
$$ОС = \frac{ИС}{1.24}$$
$$ОС = \frac{0.0312}{1.24} = 0.0252 \approx 2.5\%$$


#### Выводы

Полученная величина Отношения Согласованности (ОС) составляет примерно 2.5%. Данный показатель значительно меньше максимально допустимого порога в 10–20%. Следовательно, суждения экспертов при заполнении матрицы обладают высокой степенью согласованности, и полученные весовые коэффициенты угроз могут быть корректно использованы для оценки влияния требований безопасности на уровень риска.
